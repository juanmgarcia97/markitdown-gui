Ayuda de MarkItDown GUI

Guía de uso y referencia de formatos soportados

Formatos soportados

MarkItDown GUI puede convertir los siguientes tipos de archivos a formato Markdown:

Documentos
PDF .pdf, Word .docx, PowerPoint .pptx, Excel .xlsx .xls
Web
HTML .html .htm
Datos
CSV .csv, JSON .json .jsonl, XML .xml, RSS .rss, Atom .atom
Texto
Texto plano .txt, Markdown .md
Imágenes
JPEG .jpg .jpeg, PNG .png
Audio/Video
WAV .wav, MP3 .mp3, M4A .m4a, MP4 .mp4
Otros
EPUB .epub, Jupyter Notebook .ipynb, Outlook .msg, ZIP .zip

Flujo de conversión

Sigue estos pasos para convertir tus archivos a Markdown:

  1. Importar archivos
    Arrastra y suelta archivos sobre la zona indicada, o haz clic en "Agregar archivos" para seleccionarlos desde tu sistema.
  2. Seleccionar carpeta de salida (opcional)
    Elige una carpeta donde guardar los archivos convertidos. Si no seleccionas ninguna, se guardarán en la misma carpeta del archivo original.
  3. Presionar "Convertir"
    Inicia la conversión de todos los archivos importados. Puedes ver el progreso en la barra y cancelar en cualquier momento.
  4. Revisar resultados en vista previa
    Haz clic en un archivo convertido para ver el Markdown generado. Puedes alternar entre vista renderizada y código fuente.
  5. Copiar o abrir carpeta de salida
    Copia el contenido Markdown al portapapeles o abre directamente la carpeta donde se guardaron los archivos convertidos.
Consejo Puedes importar hasta 100 archivos a la vez. También puedes arrastrar carpetas — se procesarán los archivos compatibles del primer nivel.
